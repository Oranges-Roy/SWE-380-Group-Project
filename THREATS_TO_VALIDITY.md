A key threat to validity stems from dataset noise in mined repositories where boilerplate or placeholder files (e.g., empty SKILL.md templates) exist. Because empty files share identical character structures, similarity algorithms assign them near-perfect similarity scores ($\approx 1.0$), resulting in trivial false-positive clone pairs. To address this, future iterations of the pipeline should enforce a minimum token/line-count threshold prior to similarity analysis. (Sprint2  and forward)
